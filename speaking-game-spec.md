# Speaking Game. Спецификация

## Что это

Компьютерная игра для тренировки живой английской речи. Фразы падают сверху вниз. Игрок произносит фразу вслух, пока она проходит через зону попадания. Цель не выучить перевод, а научиться выговаривать целые фразы в естественном темпе, слитно и без пауз.

Приложение делается для одного пользователя, без аккаунтов и сервера.

## Стек

JavaScript. Десктопное приложение.

Рекомендуемая сборка Electron или Tauri 2. Tauri предпочтительнее, легче и уже использовался в проекте coffeshop.

Важное ограничение. Основной движок распознавания это Web Speech API, он работает в Chromium. Если выбран Tauri, нужно проверить, что системный webview на целевой машине поддерживает SpeechRecognition. Если нет, брать Electron.

Весь интерфейс игры на английском. Переводы фраз на русском.

## Основная механика

Фраза появляется сверху и движется вниз с постоянной скоростью.

Зона попадания это горизонтальная полоса, а не линия. Фраза должна быть полностью произнесена за время, пока она проходит зону.

Высота зоны считается от длины фразы.

```
targetWPM = 150
expectedSeconds = (wordCount / targetWPM) * 60
zoneHeight = expectedSeconds * fallSpeed * toleranceFactor
toleranceFactor = 1.4
```

Запись начинается, когда верх фразы касается верхней границы зоны. Запись останавливается, когда низ фразы покидает нижнюю границу зоны.

Фраза подсвечивается по словам по мере распознавания. Распознанное слово зажигается, нераспознанное остаётся тусклым. Это даёт игроку обратную связь прямо во время речи.

Визуально это ближе к караоке, чем к Guitar Hero. Длинные фразы занимают больше вертикального места, и это нормально.

## Распознавание речи

Движок Web Speech API, SpeechRecognition.

```
recognition.continuous = true
recognition.interimResults = true
recognition.lang = 'en-US'
```

Промежуточные результаты обязательны, иначе нельзя оценить момент произнесения.

Распознавание запускается один раз на старте забега и работает непрерывно. Не перезапускать его на каждой фразе, перезапуск даёт задержку в сотни миллисекунд и ломает тайминг.

### Сравнение сказанного с эталоном

Нормализовать обе строки перед сравнением. Нижний регистр, убрать пунктуацию, развернуть сокращения в обе стороны (gonna и going to считать совпадением, I'd и I would тоже).

Совпадение считать по словам, а не по всей строке целиком.

```
matchRatio = совпавшие слова / всего слов в эталоне
```

Порог чистого попадания 0.85.

### Чего этот движок не умеет

Web Speech API не оценивает произношение. Он оценивает распознавание. Если движок расслышал нужные слова, попадание засчитывается даже при сильном акценте.

Игра тренирует темп, связность и слитность речи. Чистоту отдельных звуков она не тренирует. Это осознанное ограничение, фонемную оценку дают только платные сервисы.

## Баллы

Четыре исхода, не три.

| Исход | Условие | Баллы |
|---|---|---|
| Чисто | matchRatio >= 0.85, уложился в зону | +10 |
| С опозданием | matchRatio >= 0.85, вышел за зону, но договорил | +4 |
| Промах по словам | matchRatio < 0.85, но речь была | 0 |
| Молчание | речи не было вообще | -5 |

Промах по словам и молчание разделены намеренно. Это разные ситуации и на повторение они влияют по-разному. Промах по словам возвращает фразу в оборот агрессивнее, молчание только штрафует баллами.

Комбо. Каждые 5 чистых подряд множитель +0.5, максимум x3. Любой исход кроме чистого сбрасывает комбо.

## Провал и повтор

Если игрок не успел, фраза продолжает падать и уходит вниз. Поток фраз не прерывается, темп забега не сбивается.

Сразу после промаха автоматически проигрывается эталонный звук фразы. Синтез речи через системный SpeechSynthesis, бесплатно, выбирать голос с lang en-US или en-GB. Во время проигрывания эталона игра встаёт на паузу, следующая фраза не появляется.

Кнопка прослушать эталон вручную тоже должна быть, на паузе и в экране результатов.

## Прогресс и повторения

Логика та же, что в words-learning-game.

Фраза считается выученной после нескольких чистых попаданий в разные дни. Попадания в один и тот же день засчитываются как одно.

```json
{
  "phraseId": "p_0142",
  "cleanHitDays": ["2026-10-19", "2026-10-21"],
  "requiredDays": 3,
  "lastSeen": "2026-10-21",
  "misses": 2,
  "learned": false
}
```

Промах по словам добавляет +1 к misses и повышает частоту показа фразы. Молчание частоту не меняет.

Выученные фразы уходят из основной ротации, но изредка возвращаются для проверки.

Прогресс хранится в локальном JSON-файле. Перенос прогресса между машинами через этот файл, как в words-learning-game.

## База фраз

Готовый JSON, генерируется отдельной задачей. Структура.

```json
{
  "id": "p_0142",
  "text": "I'll get back to you on that.",
  "translation": "Я к этому ещё вернусь.",
  "wordCount": 8,
  "difficulty": 2,
  "category": "work",
  "tags": ["contraction", "linking"]
}
```

### Критерий отбора

Фраза должна быть такой, чтобы её можно было сказать коллеге на созвоне и никто не обернулся.

Что берём.

Связки и переходы речи. Here's the thing. Let me walk you through it. Which brings me to. That said.

Рабочие формулы. I'll get back to you on that. Can we park that for now. Let me make sure I understand you correctly.

Нейтральное несогласие. I'm not sure that follows. I'd push back on that a little. That's fair, but there's another angle.

Бытовое живое. It kind of grew on me. Fair enough. It is what it is. Give it a shot.

Что не берём. Цитаты из фильмов. Мотивационные лозунги. Книжные идиомы вроде bite the bullet, которые в живой речи почти не встречаются.

### Приоритетная категория

Отдельно выделить фразы со слитным произношением, где написание и звучание расходятся.

gonna, wanna, gotta, I would've, what are you, kind of, out of

На этих фразах механика работает лучше всего. Если проговаривать их по словам, физически не уложишься в зону. Игра сама заставляет говорить слитно. Теги linking и contraction должны быть у таких фраз обязательно, и их доля в базе не меньше трети.

### Уровни сложности

1. до 5 слов, без сокращений
2. 5-8 слов, одно сокращение
3. 8-12 слов, слитное произношение
4. 12+ слов, быстрый темп, несколько связок

Игрок выбирает уровень, с которого начинает, и количество фраз в забеге.

## Интерфейс

Максимально игровой. Анимации попаданий, звук комбо, поздравления на вехах.

Экран забега. Падающие фразы, зона попадания, счёт, комбо, индикатор микрофона.

Перевод фразы по умолчанию скрыт. Показывается по наведению или по клавише, и только на паузе. Во время падения перевода нет, иначе игрок читает русский вместо того чтобы говорить.

Экран результатов. Чистые, с опозданием, промахи, молчание. Список фраз, на которых споткнулся, с кнопкой прослушать эталон у каждой.

## Репозиторий

Отдельный репозиторий, не режим существующих игр.

Рекомендуемое имя github.com/nasraddinzade/speaking-game

## Требования к сборке

После реализации проверить руками, что всё работает. Запустить приложение, пройти полный забег вслух, убедиться что распознавание реагирует, зона считается правильно, эталон проигрывается после промаха, прогресс сохраняется в файл и подхватывается при следующем запуске.

Отдельно проверить тайминг на фразе из 12+ слов. Это самый вероятный источник ошибок в расчёте зоны.
